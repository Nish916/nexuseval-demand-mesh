# Sources and Claim Map

Primary public source:
https://github.com/Scottcjn/rustchain-mcp/blob/main/README.md

## Claim → source mapping

### Claim: rustchain-mcp is a Python MCP server connecting AI agents to RustChain, BoTTube and Beacon
Source: README opening description and Answer-First FAQ.

### Claim: the server exposes RustChain wallet/balance/transfer, bounty/discovery and network tools
Source: README sections `RustChain (Blockchain)`, `Available Tools`, and `Ecosystem & Discovery`.

### Claim: BoTTube tools include search/discovery, profiles/trending, upload, comment and vote
Source: README section `BoTTube Platform`.

### Claim: Beacon tools include discover, register, heartbeat/status, messaging and contracts
Source: README section `Beacon Messaging`.

### Claim: install command is `pip install rustchain-mcp`
Source: README `Installation` section.

### Claim: an MCP-compatible client can launch/use the server
Source: README `Quick Start` and `For Other MCP Clients` sections.

## Editorial guardrails
- No price forecast.
- No guaranteed earnings claim.
- No claim that installing the package automatically earns RTC.
- No invented benchmark numbers.
- No claim that every tool is safe to call without operator policy; money-moving actions are explicitly described as actions that should be verified before use.
