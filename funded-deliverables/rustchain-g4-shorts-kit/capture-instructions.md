## Editing guardrails

- Keep the README URL/browser chrome visible for at least one source shot.
- Do not animate an RTC balance, payout, or revenue number; this package does not verify earnings.
- Do not use photos of Apple hardware unless the publisher owns or licenses them; repository captures are sufficient.
- If the public README changes before publication, re-check the multiplier values and update the script rather than preserving stale numbers.
