A publication-ready explainer that separates two RustChain mechanisms that are easy to conflate:

1. RIP-200's **1 physical CPU = 1 vote / round-robin participation** model.
2. Proof-of-Antiquity's **antiquity-weighted reward allocation** after hardware attestation.

This package does not claim that antiquity multipliers are speed benchmarks, token prices, guaranteed earnings, or investment returns.
