## Claim 4 — Six hardware-fingerprint checks
Source: README section `AI-Augmented Consensus` → `Hardware Fingerprinting (6 Checks No VM Can Fake)` lists:
1. Clock-Skew & Oscillator Drift
2. Cache Timing Fingerprint
3. SIMD Unit Identity
4. Thermal Drift Entropy
5. Instruction Path Jitter
6. Anti-Emulation Detection

## Claim 5 — The system is intended to distinguish physical machines from VMs/emulators
Source: README project description says RustChain uses AI-powered hardware fingerprinting to verify real physical machines rather than cloud VMs / Docker containers / rented hash power, and its validation section describes anti-emulation and cross-validation checks.

## Editorial guardrail
The package intentionally does **not** repeat unverified token-price, fiat-income, investment-return or guaranteed-profit claims. Multipliers are presented as protocol/project parameters exactly as published by RustChain, with an on-screen disclosure.
