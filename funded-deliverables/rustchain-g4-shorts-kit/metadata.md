## Description

RustChain documents a 2.5x Proof-of-Antiquity multiplier for PowerPC G4 hardware and 0.8x for modern x86_64. This short explains the project’s stated design: physical-hardware verification and preservation, not a claim that a G4 is faster than a modern CPU.

Source and code: https://github.com/Scottcjn/Rustchain

This package was prepared as a compensated bounty submission for the Elyan Labs distribution-package round. Technical claims are mapped to public sources in `SOURCES.md`.
