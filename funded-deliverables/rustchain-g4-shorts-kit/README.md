## Rights / production note

This package contains original script, shot instructions, and metadata written for the bounty. The recommended visuals are captures of the cited public RustChain repository and locally typed terminal/text overlays, so a publisher can produce the clip without unlicensed b-roll.

## Accuracy boundary

The package deliberately says "multiplier" rather than claiming a measured dollar/RTC earnings rate. It does not claim that a G4 literally produces 3.125x the RTC of every modern machine under all conditions; it only states the public project's documented multiplier values and explains the project's Proof-of-Antiquity premise.
