## Description
RustChain’s public protocol docs describe Proof of Antiquity: a system that assigns higher published multipliers to some vintage hardware and uses a six-check hardware fingerprint to distinguish real physical machines from emulated environments.

This short uses only claims published in the current RustChain repository. The examples shown — PowerPC G4 (2003) at 2.5× and modern x86_64 at 0.8× — are protocol/project multipliers, not dollar returns or profit promises.
